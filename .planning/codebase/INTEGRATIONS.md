# External Integrations

**Analysis Date:** 2026-08-07

## APIs & External Services

**Implemented Browser Resources:**
- Google Fonts - loads Manrope and Golos Text from Google-hosted CSS/font endpoints.
  - SDK/Client: browser `<link>` resources declared by the root route in `src/routes/__root.tsx`.
  - Auth: none.
- SoundHelix - supplies the fixed demonstration MP3 used by the notebook podcast player.
  - SDK/Client: native HTML `<audio>` in `src/components/notebook/artifacts/PodcastPlayer.tsx`.
  - Auth: none.
- External knowledge links - `src/lib/sources.ts` synthesizes links to `hbr.org` or `wiki.bi.group` from mock card metadata; these are navigational URLs, not API calls or live content ingestion.
  - SDK/Client: ordinary browser links generated by `buildNotebookSources` in `src/lib/sources.ts`.
  - Auth: none in this application.

**Lovable Platform:**
- Lovable editor/build integration - project metadata is stored in `.lovable/project.json`, the build preset is imported by `vite.config.ts`, and repository-to-editor synchronization is documented in `AGENTS.md` and `README.md`.
  - SDK/Client: `@lovable.dev/vite-tanstack-config` in `package.json` plus editor-injected browser hooks consumed by `src/lib/lovable-error-reporting.ts`.
  - Auth: managed outside application code; no Lovable token or credential is referenced by `src/`.

**Documented Backend Contracts (implementation not present in this repository):**
- The architecture documents name OpenAI, Anthropic, Google AI Gateway, NotebookLM, OneDrive, BILife SSO, MinIO/S3, and PostgreSQL/pgvector in `00_docs/05_Архитектура_системы.md`, `00_docs/12_Инфраструктура_и_DevOps.md`, and `00_docs/27_Интеграции_и_контракты.md`.
- `00_docs/openapi.yaml` and `00_docs/10_API_контракты.md` define a broad `/api/v1` contract, but `package.json` contains no SDK for those providers, `src/` contains no HTTP API client or `createServerFn` implementation, and the only executable routes are the UI routes in `src/routes/`.
- Treat these documents as separate-system contracts, not as active dependencies of the current TanStack application. The referenced FastAPI/Python manifests and backend source tree are not present in this repository.

## Data Storage

**Databases:**
- No database is connected by executable application code. `package.json` has no database driver or ORM, and `src/` has no database client.
- The UI's seed knowledge catalog is an in-memory TypeScript dataset in `src/data/mockCards.ts`; council and advisor seed data live in `src/data/council.ts` and `src/data/advisor.ts`.
- PostgreSQL with pgvector is specified only by `00_docs/05_Архитектура_системы.md`, `00_docs/06_Модель_данных.md`, and `00_docs/22_Физическая_схема_БД.md`; no connection variable or client is consumed by current code.

**File Storage:**
- Source-controlled static assets only under `public/`, including persona images under `public/personas/`.
- Notebook export features create browser `Blob` objects and temporary object URLs in `src/components/notebook/ArtifactDialog.tsx`, `src/components/notebook/StudioPanel.tsx`, and `src/components/notebook/SourceReaderDialog.tsx`; exports are downloaded locally and are not uploaded to a service.
- MinIO/S3 and OneDrive are contract-only integrations described in `00_docs/27_Интеграции_и_контракты.md`; no storage SDK is declared in `package.json`.

**Caching:**
- TanStack Query provides an in-memory `QueryClient` per router instance in `src/router.tsx`, exposed by `src/routes/__root.tsx`; no remote query cache or persistence adapter is configured.
- Browser `localStorage` is the durable client store through `src/hooks/useLocalStorage.ts` and the feature hooks in `src/hooks/useAppState.ts`.
- No Redis, CDN API client, or server-side cache is integrated in executable code.

## Authentication & Identity

**Auth Provider:**
- None in the executable application. Routes under `src/routes/` do not enforce login, no auth SDK appears in `package.json`, and no session/token code appears under `src/`.
  - Implementation: public UI routes with browser-local state.
- TanStack Start CSRF middleware is explicitly re-enabled for server functions in `src/start.ts`; this is request-forgery protection, not user authentication. No server functions are currently defined under `src/`.
- The sidebar component writes a UI-state cookie in `src/components/ui/sidebar.tsx`; it is not an authentication or session cookie.
- BILife/SSO with bearer JWT is described as a backend contract in `00_docs/10_API_контракты.md`, `00_docs/11_Безопасность_и_комплаенс.md`, and `00_docs/27_Интеграции_и_контракты.md`, but no provider integration exists in this executable project.

## Monitoring & Observability

**Error Tracking:**
- Lovable preview/editor telemetry only. `src/lib/lovable-error-reporting.ts` forwards React boundary failures to optional `window.__lovableEvents` and `window.__lovableReportRuntimeError` hooks when the editor injects them.
- No Sentry, Datadog, OpenTelemetry, or other monitoring SDK is declared in `package.json` or imported by `src/`.

**Logs:**
- Browser and server errors use `console.error` in `src/routes/__root.tsx`, `src/start.ts`, and `src/server.ts`.
- `src/lib/error-capture.ts` wraps server-side `console.error`, captures error/cause details in memory for five seconds, and lets `src/server.ts` recover context from errors swallowed by the SSR stack.
- Operational metrics and tracing are described in `00_docs/13_Наблюдаемость_и_SRE.md`, but the corresponding backend endpoints/exporters are not present in `src/`.

## CI/CD & Deployment

**Hosting:**
- Cloudflare Workers-compatible output through Nitro's `cloudflare-module` preset. The selection is supplied by the Lovable configuration noted in `vite.config.ts`; generated evidence is in `.output/nitro.json` and `.output/server/wrangler.json`.
- Static assets are bundled from `public/` and exposed through the generated Cloudflare asset binding shown in `.output/server/wrangler.json`.
- A Bun-based development container is available through `Dockerfile` and `docker-compose.yml`; it runs the Vite dev server rather than a production deployment command.
- Lovable project synchronization is active at the repository level as documented in `AGENTS.md`; it is a development/editor integration, not an application runtime API.

**CI Pipeline:**
- None detected. There is no `.github/workflows/` pipeline or other source-controlled CI configuration.
- Build, test, lint, format, preview, and development commands are local package scripts in `package.json`.
- Generated `.output/nitro.json` exposes Wrangler preview/deploy commands for the built artifact, but no source-controlled workflow invokes them.

## Environment Configuration

**Required env vars:**
- None for the current executable application. No `process.env`, `import.meta.env`, `VITE_*`, database URL, provider key, or auth variable is read by `src/`.
- `vite.config.ts` indicates the Lovable preset supports `VITE_*` injection, but this capability is unused by application source.
- Names listed in `00_docs/12_Инфраструктура_и_DevOps.md` configure the documented backend system and are not consumed by this repository's TanStack runtime.

**Secrets location:**
- No secret-bearing environment file is present at the repository root.
- `.gitignore` reserves ignored `.dev.vars` and `*.local` locations for local configuration; neither is part of the committed application configuration.
- External deployment/editor credentials are managed outside this codebase; no secret manager integration is implemented under `src/`.

## Webhooks & Callbacks

**Incoming:**
- None. `src/server.ts` exposes the generic TanStack SSR `fetch` handler, and `src/routes/` contains page routes only; no webhook or callback endpoint is implemented.
- Connector and auth endpoints described in `00_docs/openapi.yaml` are contracts without matching executable route handlers in this repository.

**Outgoing:**
- No webhook delivery logic. Executable source contains no `fetch`, Axios client, queue publisher, or webhook SDK.
- Browser-managed resource requests are limited to Google Fonts in `src/routes/__root.tsx`, the sample SoundHelix audio in `src/components/notebook/artifacts/PodcastPlayer.tsx`, optional navigation to generated source URLs from `src/lib/sources.ts`, and Lovable editor telemetry through injected hooks in `src/lib/lovable-error-reporting.ts`.

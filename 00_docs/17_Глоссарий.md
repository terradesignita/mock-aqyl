## Термины

- **BI AQYL** — название проекта корпоративной AI-платформы управления знаниями BI Group.
- **Insight Card** — структурированный артефакт с выводами, фреймворками, рекомендациями и ссылками на источники. В БД: таблица `artifacts` (kind=`card`) + `artifact_versions` (по языкам).
- **RAG** — Retrieval Augmented Generation, генерация ответа на основе найденных релевантных фрагментов. Используется для INTERNAL scope.
- **Groundedness** — степень опоры ответа на проверяемые источники (цитаты из `artifact_citations`).
- **Citation Coverage** — доля ответов с корректными ссылками на источник. Целевой KPI: >= 95%.
- **Ingestion** — процесс обнаружения, загрузки и подготовки контента. Реализован в `backend/services/ingestion.py`.
- **Chunk** — фрагмент текста фиксированного размера для поиска и embedding. Параметры: 220 токенов, overlap 40, хранится в таблице `chunks`.
- **Vector DB** — векторный индекс чанков для semantic search. Реализован через расширение `pgvector` в PostgreSQL 17 (HNSW-индекс, m=16, ef_construction=64, cosine similarity).
- **Hybrid Search** — гибридный поиск: keyword (BM25/tsvector, вес 0.45) + semantic vector (вес 0.55). Реализован в `backend/services/search.py`.
- **RBAC** — контроль доступа по ролям: viewer / editor / owner / admin.
- **ABAC** — контроль доступа по атрибутам: `business_unit`, `geo`, `position`.
- **PII** — персональные данные (email, телефон, ИИН, паспорт). Маскируются в `backend/security.py` до передачи в LLM.
- **DLP** — Data Loss Prevention. Pre-LLM masking через `PII_PATTERNS` regex.
- **SLO/SLI** — целевые и измеряемые метрики надежности сервиса (доступность 99.5%, P95 поиска <= 1.5s).
- **Scope** — режим работы платформы: `INTERNAL` (RAG по внутренним документам) или `EXTERNAL` (HBS через NotebookLM).
- **Karpathy Wiki** — слой LLM-генерируемых markdown wiki-страниц поверх ingested документов. Таблицы: `wiki_pages`, `wiki_cross_refs`, `wiki_lint_jobs`. Обновляется каждые 6 часов.
- **WikiPage** — отдельная wiki-страница о концепции/теме. Типы (`page_type`): concept, summary, faq, comparison, reference, procedure, glossary.
- **WikiCrossRef** — направленная ссылка между двумя wiki-страницами, извлекается из маркеров `**[concept]**`.
- **WikiLintJob** — задача проверки качества wiki-страниц. Статусы: `running` → `completed` / `failed`.
- **NotebookLM** — Google-сервис для генерации артефактов по EXTERNAL scope (HBS). Поддерживает: quiz, report, podcast, slides. notebook_id=72c8f1f7, 33 PDF HBS загружены.
- **Artifact** — генерируемый AI-контент по документу или теме. Виды (`kind`): card, test, presentation, report, podcast, infographic.
- **ArtifactVersion** — версия артефакта на конкретном языке. Содержит `content_json`, `model_name`, `translation_pending`.
- **Pipeline Job** — фоновая задача обработки (`pipeline_jobs`). Виды (`kind`): ingest, generate, lint, translate.
- **Topic** — тематическая коллекция документов. Поля: `slug`, `difficulty`, `business_unit`, `owner_email`, иерархия через `parent_id`.
- **TopicMember** — участник темы с ролью (viewer/editor/owner).
- **Skill** — системный промпт-режим для AI (category: mode / position). Хранится в таблице `skills`.
- **Dossier** — набор всех артефактов по документу или теме (`GET /api/v1/artifacts/dossier`).
- **Source** — источник документов: `MANUAL`, `FOLDER_SYNC`, `ONEDRIVE`.
- **Classification** — уровень конфиденциальности документа: PUBLIC / INTERNAL / CONFIDENTIAL / RESTRICTED.
- **Access Layer** — слой доступа к документу: `open` (всем) или restricted (фильтр по `allowed_positions`).
- **ADR** — Architecture Decision Record, фиксирует архитектурные решения (см. [[20_ADR_реестр]]).
- **TTS** — Text-to-Speech. Модели: `gpt-4o-mini-tts` (голоса: alloy, nova). Реализован в роутере `speech`.
- **Whisper** — OpenAI ASR-модель для транскрипции аудио (`whisper-1`). Fallback: локальный Whisper (`WHISPER_MODEL=small`).
- **Transcript Segment** — сегмент транскрипции аудио/видео. Таблица: `transcript_segments`.
- **GeneratedAsset** — файловый AI-артефакт (изображение, PDF, PPTX). Таблица: `generated_assets`.

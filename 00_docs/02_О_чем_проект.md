## Контекст

Сейчас знания распределены по файлам (`.pdf`, `.docx`, `.mp3`, `.png`) в OneDrive-структуре. Текущая HTML-витрина решает задачу навигации частично, но не покрывает:
- автоматический ingestion и дедупликацию;
- единый поиск по смыслу;
- генерацию карточек инсайтов и диалог по контексту;
- мультиязычную выдачу (RU/EN/KK/UZ/AZ);
- корпоративные требования безопасности и масштабируемости.

## Цель продукта

Построить корпоративную AI-платформу знаний **BI AQYL**, которая объединяет:
- **внешнюю экспертизу** (кейсы HBS, книги, лекции — EXTERNAL scope);
- **внутреннюю экспертизу** (Lessons Learned BI — INTERNAL scope);
- единый UX в корпоративной среде (BILife / SSO).

## Два режима работы (scope)

`scope` — атрибут управления доступом и маскирования данных, **не** определяет способ обработки. Оба режима используют одинаковый RAG-пайплайн.

| Scope | Источник | Обработка | Провайдер AI |
|---|---|---|---|
| `INTERNAL` | Внутренние документы BI (Lessons Learned, проекты) | Полный RAG: chunk → embed → pgvector | OpenAI / Anthropic / Google / Ollama; `MASK_EXTERNAL_LLM=true` |
| `EXTERNAL` | Внешняя библиотека (HBS, книги, лекции) | Полный RAG: chunk → embed → pgvector | OpenAI / Anthropic / Google / Ollama |

### NotebookLM

NotebookLM (Google) используется **исключительно в Studio** для генерации богатых форматов (quiz, подкаст, презентация) для обоих scopes. Это явный пользовательский запрос, не часть автоматического ingestion-пайплайна.

## Целевые пользователи

- `Wave 1`: Top-100 руководителей.
- `Wave 2`: Top-500.
- `Wave 3`: массовый корпоративный доступ.

## Границы проекта

### In scope
- Загрузка и обработка документов/аудио (pdf, docx, pptx, mp3, png).
- Карточки инсайтов + Q&A по карточке.
- Гибридный поиск (keyword + vector, веса 0.45 лексика / 0.55 семантика).
- Роли доступа (viewer/editor/owner/admin), ABAC по business_unit и geo, аудит.
- Мультиязычность RU/EN/KK/UZ/AZ.
- Karpathy Wiki layer: автогенерация wiki-страниц при ingest, обновление каждые 6 ч.
- NotebookLM connector: quiz, report, podcast, slides для EXTERNAL scope.
- **Twin CEO Simulator**: AI-тренажёр переговоров — 10 архетипов CEO с уникальными MD-профилями, фазовый UX (setup → chat → debrief), голосовой ввод, AI-дебрифинг по итогам сессии.

### Out of scope (на 1-й фазе)
- Автогенерация курсов LMS end-to-end.
- Полная замена корпоративного DMS.
- Real-time синхронизация с >10 внешними источниками одновременно.

## Ключевая продуктовая идея

Паттерн **«две кнопки»**:
- `Внутренний опыт BI` — поиск по Lessons Learned (INTERNAL scope).
- `Мировой опыт` — поиск по внешней библиотеке HBS (EXTERNAL scope).

На уровне архитектуры это один pgvector-индекс с фильтрацией по `scope`. Scope управляет доступом и масштабом маскирования данных перед отправкой во внешние LLM, но не меняет pipeline обработки.

## Текущая реализация

- **23 REST-роутера**: advisor, artifacts, assets, audit, auth, cards, chat, connectors, documents, glossary, health, images, jobs, metrics, notifications, search, skills, speech, studio, tags, topics, twin, uploads, wiki.
- **Порт приложения**: 8040 (backend и nginx gateway).
- **База данных**: PostgreSQL 17 с расширением pgvector, порт 5433.
- **Хранилище файлов**: MinIO (S3-compatible), порт 9000.
- **Режим аутентификации**: `demo` (любые credentials принимаются, роль берётся из config).

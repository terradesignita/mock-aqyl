## Стратегия тестирования

- Unit tests: бизнес-логика сервисов.
- Integration tests: БД, очередь, векторный индекс.
- E2E tests: ключевые пользовательские сценарии.
- AI eval tests: качество и groundedness ответов.

## Критические сценарии E2E

- Upload → indexed → card generated (Time-to-Card <= 30 мин).
- Search → open card → ask question with citations.
- RBAC restrictions on RESTRICTED content (negative tests).
- Translation fallback when locale missing (`translation_pending=true`).
- Position-based access filter (`access_layer`, `allowed_positions`).
- Wiki lint cycle: ingest → wiki page generated → lint job → status `passing`.

## Quality gates в CI

- unit coverage >= 70% (backend critical modules >= 85%).
- 0 critical vulnerabilities.
- Schema migration checks (Alembic).
- Snapshot tests для API контрактов.
- `ruff` lint (line-length=100, target-version=py312) — 0 ошибок.

## AI quality evaluation

Набор `golden questions`:
- минимум 200 вопросов по реальным кейсам (статус: OI-011 — в работе).
- Ручная разметка expected evidence.
- Автоматическая проверка:
  - citation presence (поле `citations` в ответе);
  - semantic similarity;
  - factual consistency.

## A. JSON-схема карточки (artifact kind=card)

Хранится в `artifact_versions.content_json`. Структура `SCHEMA_CARD`:

```json
{
  "type": "object",
  "required": ["title", "executive_summary", "core_insight", "citations"],
  "properties": {
    "title": {"type": "string"},
    "executive_summary": {"type": "string"},
    "core_insight": {"type": "string"},
    "framework": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["step", "description"],
        "properties": {
          "step": {"type": "string"},
          "description": {"type": "string"}
        }
      }
    },
    "citations": {
      "type": "array",
      "minItems": 1,
      "items": {
        "type": "object",
        "required": ["chunk_id", "source_anchor"],
        "properties": {
          "chunk_id": {"type": "string"},
          "source_anchor": {"type": "string"}
        }
      }
    }
  }
}
```

## E. Структура Wiki-страницы (Karpathy format)

Обязательная структура для `wiki_pages.markdown_content`:

```markdown
# <Title>

## Overview
<2-3 sentences: what this concept/topic is and why it matters>

## Key Concepts
<Bullet list of 3-6 core ideas. Use **[concept_name]** for cross-refs>

## Details
<Detailed explanation, 200-400 words>

## Common Pitfalls
<2-4 bullet points>

## Related Topics
<Bullet list using **[concept_name]** format>

[Source: <document_title>]
```

Ограничения: 1500–2500 символов, `page_type` ∈ {concept, summary, faq, comparison, reference, procedure, glossary}.

## G. Checklist запуска нового источника

```text
[ ] Юридическая проверка источника
[ ] Назначен владелец контента (owner_email в topics)
[ ] Настроена классификация данных (Classification enum)
[ ] Выбран scope: INTERNAL (RAG) или EXTERNAL (NotebookLM)
[ ] Протестирован ingestion на 20+ файлов
[ ] Проверены citations в карточках (coverage >= 95%)
[ ] Настроены дашборды и алерты
[ ] Wiki-страницы сгенерированы и прошли lint (статус passing)
```

## H. Checklist новой LLM-модели

```text
[ ] Добавлена в Model Registry (provider, model_name, latency/cost profile)
[ ] Прописана в config.py (env-переменная)
[ ] Добавлена в fallback chain (ai_provider=auto)
[ ] Regression eval на golden dataset пройден
[ ] Hallucination rate <= порогового значения
[ ] Обновлён ADR если это архитектурное изменение
```

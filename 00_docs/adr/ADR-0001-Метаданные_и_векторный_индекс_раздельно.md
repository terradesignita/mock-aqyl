# ADR-0001: Метаданные и векторный индекс раздельно
- Status: accepted
- Date: 2026-03-10

## Context

Нужно обеспечить быстрый semantic retrieval и предсказуемые транзакции по бизнес-данным.

## Decision

Использовать раздельные хранилища:
- PostgreSQL для метаданных и бизнес-сущностей.
- Vector DB для embeddings и similarity search.

## Alternatives Considered

- Единая БД для всего: проще операционно, но хуже масштабируется по retrieval-нагрузке.

## Consequences

- Плюсы: независимое масштабирование, лучшая latency для vector search.
- Минусы: усложнение консистентности и backup-стратегии.

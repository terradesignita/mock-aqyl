# Персоны «Консилиума» — системные промпты

По одному файлу на персону: психологический профиль (ценности, слепые зоны, реакция под давлением, конфликты с другими персонами) + готовый system prompt для будущей реальной LLM-интеграции. Сейчас `src/data/council.ts` использует детерминированные mock-функции (`buildPersonaTake`, `buildVerdict`), эти файлы — задел на будущее.

Гвардрейл в каждом файле: имя персоны вымышленное, реальный лидер — только стилевой ориентир, никогда не источник цитаты.

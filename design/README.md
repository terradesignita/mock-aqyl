# Разбор UX — исходники канваса

Здесь лежат исходники опубликованного разбора: [BI AQYL · разбор UX](https://claude.ai/code/artifact/63fc6696-f5b2-40cb-89ad-50702b4d87a5).

Каждый `*.dc.html` — один artboard на бесконечном холсте, `canvas.json` задаёт
раскладку, страницы и записки. Собранный файл `bi-aqyl-ux-razbor.html` в репозиторий
не входит: это 2,7 МБ, которые целиком генерируются из этих исходников.

## Как пересобрать

`support.js`, на который ссылаются artboard-файлы, приходит из окружения канваса —
локально его нет и он не нужен. Сборка и публикация идут через скилл `/design`
(Claude Code): он копирует шаблон payload'а, вклеивает в него исходники и
публикует результат как артефакт. Порядок:

1. Правим `*.dc.html` и при необходимости `canvas.json`.
2. Собираем свежую копию payload'а: `seed-canvas.mjs --template … --out bi-aqyl-ux-razbor.html --artboard … --canvas canvas.json`.
3. Проверяем: `seed-canvas.mjs --check bi-aqyl-ux-razbor.html`.
4. Публикуем тем же URL и с тем же `contract`, чтобы ссылка не менялась.

Токены взяты из `src/styles.css` дословно: `--primary oklch(0.538 0.256 262.4)`,
`--radius 0.5rem` (карточка 10px), Golos Text + Manrope, база 15px.
